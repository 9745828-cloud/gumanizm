# Гуманистика. Быть человеком

Упрощённый макет портала по документу **структура портала.docx**.

**Humanistics: Being Human**

## Структура (9 разделов)

| # | Раздел | Маршрут |
|---|--------|---------|
| 01 | Гуманистика — имя человечности | `/razdel/gumanistika-imya-chelovechestva` |
| 02 | «Судьба мира» начинается с человека | `/razdel/sudba-mira` |
| 03 | Мораль выше правил | `/razdel/moral-vyshe-pravil` |
| 04 | Единая человечность — разные пути | `/razdel/edinaya-chelovechestvo` |
| 05 | Семья — начало мира | `/razdel/semya` |
| 06 | Когда человек забывает, что он человек | `/razdel/kogda-chelovek-zabyvaet` |
| 07 | Те, кто выбрал добро | `/razdel/te-kto-vybral-dobro` |
| 08 | Мир, который мы создаём | `/razdel/mir-kotoryy-my-sozdaem` |
| 09 | Начни с себя | `/razdel/nachni-s-sebya` |

У каждого раздела — 3 подраздела. **Инфографика не отдельный раздел**: нау-поп блоки встроены в главы (поле `visual` в `content.ts`), где помогают раскрыть идею.

Сейчас визуалы-макеты есть в разделах 01, 05, 06, 09 — как примеры интеграции.

## Дизайн

Современный минимализм: крем + ink + teal, Fraunces + DM Sans.
